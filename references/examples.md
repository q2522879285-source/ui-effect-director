# 引导与转译示例

示例说明选法，不是固定风格或默认技术栈。所有数值都是没有现有 token 时的试作建议。需要完整操作契约时按 interaction-spec 补齐相关字段。

## 1. 产品页面：高级但不花哨

**用户**：“后台这些卡片太死，想高级一点，但每天都要用，别花里胡哨。”

**推荐**：保留布局，先理清标题/数值层级；卡片只做轻微悬停抬升，按钮按下即时反馈。不让整组卡片每次加载都轮流飞入。

**转译**：Elevation + hover feedback / press feedback。层级主要靠静态关系，动效只反馈操作。

**可复制操作描述**：“只优化统计卡片和按钮，保留现有布局、字体与颜色 token。可点击卡片在指针悬停时轻微抬升，离开恢复；按钮按下即时反馈，释放或取消恢复。试作位移 2px、过渡 140ms；触控不依赖 hover，键盘焦点保持清晰。减少动态效果时取消位移。检查快速移入移出、按压取消与键盘操作。”

## 2. 标签切换：内容连贯，不只是划线动

**用户**：“点标签的时候下面那条线滑过去，内容不要生硬地一下换掉。”

**推荐**：选中线位置/宽度连续变化，面板短淡入；不让整个内容区长距离横飞。

**转译**：Tabs + active indicator transition + panel fade。先确认是真正的关联面板还是路由导航；远程加载面板优先手动激活。

**可复制操作描述**：“为关联面板的 tabs 添加滑动选中指示器，沿当前与新标签的位置和宽度过渡；选中状态立即更新，内容就绪后短淡入，加载/失败用真实状态显示。保持 tabs 语义、方向键与 Enter/Space 手动激活。连续切换以最新选择为准，不能展示旧请求结果。使用既有 token，无 token 时先试 180ms；减少动态效果时直接切换并保留选中线。”

## 3. 品牌展示：滚动叙事与普通 reveal 分开

**用户**：“往下滑的时候产品一点点展开，文字分层出来，但不要把滚动锁死。”

**推荐**：产品展开进度绑定一个有限滚动区间；短文字组进入视口后依次出现。前者是跟着滚动，后者是到点播放，不用一套延迟混做。

**转译**：Scroll-driven animation + scroll-triggered reveal + stagger。

**可复制操作描述**：“仅为产品展示段定义展开前后状态，将展开进度映射到该段滚动范围，反向滚动能连续回退；文字小组首次进入视口后轻微位移淡入，交错间隔先试 40ms，长组不累积等待。保持原生滚动与内容可读；低动态偏好或滚动动画能力不可用时展示完整静态产品和文字。检查反向滚动、短屏、键盘滚动与降级。”

## 4. 跟手拖动：跟随阶段与收尾阶段分开

**用户**：“卡片能拖，拖的时候跟手，松手有点弹性，别像等它播完动画。”

**推荐**：拖动阶段直接映射输入；松手后才做边界归位的轻弹性，不对每次指针变化加慢速过渡。

**转译**：Direct manipulation + constrained drag + spring settle。

**可复制操作描述**：“拖动卡片时实时跟随指针，位移限制在容器内；拖动中不叠加延迟过渡。释放时按有效落点提交一次，越界则轻弹性归位，取消恢复原状态；新拖动能打断收尾。提供按钮/键盘替代完成同一动作。减少动态效果时直接落位。检查取消、越界、连续拖动与触控滚动冲突。”

## 5. 模糊浮层：只补会改变结论的问题

**用户**：“点按钮出来一块磨砂的面板，有点高级。”

**先问**：“面板打开后，原页面还要能操作吗？”

若需要阻断背景，转成 modal dialog + frosted glass；若仍要操作背景，转成 non-modal panel / anchored popover + frosted glass。动效可沿锚点轻微进入，但材质和语义是两层。

**材质操作描述**：“面板背景半透明并模糊后方图像，文字本身保持清晰不透明，边缘轻微分离；在明暗背景上保持可读。backdrop-filter 不可用时用足够不透明的背景保留对比。按已选的模态/非模态语义实现键盘、焦点与关闭；不只加遮罩就称为模态。”

## 6. 只有截图

**用户**：“照这个图的感觉，鼠标过去是不是会倾斜？”

“图里能看到透视和抬升，不能确定有没有 hover tilt。可以用指针轻倾斜复现类似空间感；若主要用手机，静态层级更可靠。”随后分别给观察事实与建议机制；不要断定源站用某框架，也不要未经请求修改项目。
